# 🎨 UI/UX Design & User Interface Project — UC08 (Senac EAD)

Bem-vindo ao repositório oficial da Unidade Curricular **Desenvolver projeto de interface para melhor experiência do usuário** do curso Técnico em Desenvolvimento de Sistemas do Senac EAD. Este espaço documenta a jornada completa de conceção, pesquisa, prototipagem e design de interfaces focadas na centralidade do utilizador.

---

## 🚀 Visão Geral do Módulo
O objetivo desta UC é transitar da teoria à prática no universo do **UI/UX Design**, aplicando metodologias ágeis de investigação de utilizadores, arquitetura de informação, criação de *wireframes* estruturais e prototipagem interativa de alta fidelidade. Cada etapa foi desenhada para resolver problemas reais de negócio com empatia, usabilidade e acessibilidade.

---

## 📂 Estrutura e Desenvolvimento das Atividades

### 🔍 Atividade 01 — Pesquisa de Utilizador, Personas e Mapas de Empatia
* **Foco:** Investigação qualitativa e quantitativa orientada às necessidades reais dos utilizadores.
* **Entregáveis & Metodologia:** 
  * Condução de formulário estruturado (Google Forms) com questões focadas no contexto de sistemas de refeitórios e controlo de fluxo de alimentos.
  * Análise de dados para a criação de **personas** detalhadas e **mapas de empatia**, mapeando dores, necessidades, comportamentos e objetivos dos futuros utilizadores do sistema.
  * Relatório técnico estruturado integrando os resultados da pesquisa qualitativa.

### 📐 Atividade 02 — Arquitetura de Informação e Wireframes (Sistema da Pizzaria)
* **Foco:** Conção estrutural de baixa/média fidelidade (wireframing) para o sistema desktop do empreendimento do Sr. Manoel.
* **Entregáveis & Funcionalidades Modeladas:**
  * **Tela de Login e Gestão de Erros:** Estruturas de autenticação segura e feedback visual intuitivo para credenciais inválidas.
  * **Módulo de Controlo de Caixa:** Arquitetura de fluxo financeiro com distinção clara entre entradas (pagamento de clientes) e saídas (fornecedores), destacando o campo de **Saldo** em evidência visual.
  * **Módulos de Cadastro:** Organização ergonómica de campos essenciais para o **Cadastro de Clientes** (com pontos de referência para tele-entrega) e **Cadastro de Fornecedores**, priorizando a acessibilidade e a eficiência operacional.

### ✨ Atividade 03 — Prototipagem de Alta Fidelidade e Interatividade (Figma)
* **Foco:** Materialização visual avançada e prototipagem interativa de alta fidelidade.
* **Entregáveis & Tecnologias Aplicadas:**
  * Transposição dos *wireframes* estáticos para protótipos totalmente interativos no **Figma**.
  * Aplicação de conceitos avançados de **UI Design** (hierarquia visual, paleta de cores harmoniosa, tipografia legível, imagens reais e consistência de componentes).
  * Simulação de fluxos de navegação reais entre ecrãs, incluindo o tratamento de exceções com a ativação dinâmica da tela de erro e interações fluidas para o operador do sistema.
